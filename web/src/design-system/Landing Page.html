Guides across any site

Try it yourself

Set up in under two minutes.

No accounts, no credentials — we provide everything.

1
Load the extension

Download and load Ouija unpacked in Chrome. chrome://extensions → Developer Mode → Load unpacked.

2
Enter a demo API key

Click the Ouija icon and paste one of these:

ouija_demo_shopify_2025 Shopify flow
ouija_demo_stripe_2025 Stripe KYB
3
The sidebar appears

Ouija greets you and begins guiding — highlighting elements, pointing the way, verifying each step. Press ` to toggle.

4
Follow the guide

Ouija walks you through the full journey — across sites if needed. At the end, it links you to the admin panel showing your own session.
